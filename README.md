## 📂 Completed Labs

### 🔴 [Wazuh Brute Force Detection Lab](./Wazuh-Lab/incident-report.md)
Deployed Wazuh SIEM on Ubuntu 22.04 and enrolled a Windows 11 agent. Simulated 
a brute force attack against a local account, triggering a custom detection rule 
(Rule ID 100002). Investigated the full alert lifecycle in OpenSearch Discover, 
filtered logs by agent and severity, and exported evidence as CSV. Mapped findings 
to MITRE ATT&CK T1110 — Brute Force under Credential Access.

### 🔵 [Incident Triage Report — Brute Force Attack](./incident-report-001-brute-force.md)
Triaged a simulated brute force alert. Applied the WHO/WHAT/WHEN/WHERE/WHY triage 
framework, assessed CIA triad impact, and documented containment recommendations 
as a formal Tier 1 analyst ticket.

### 🔵 [Windows Log Analysis Lab](./lab-002-windows-log-analysis.md)
Configured Windows 11 audit policies via secpol.msc and deliberately generated 
real security events. Analyzed Event IDs 4624, 4625, 4720, 4732, and 4726 manually 
in Event Viewer to understand attack patterns.

### 🔵 [Wireshark DNS Traffic Analysis](./lab-003-wireshark-dns-analysis.md)
Captured live DNS traffic on Kali Linux using Wireshark. Identified DNS query and 
response patterns, analyzed port 53 UDP traffic, and investigated simulated DNS 
tunneling behavior using Base64 encoded queries.

### 🔵 [Network Recon Detection Lab](./lab-004-network-recon-detection.md)
Used nmap from Kali Linux to perform reconnaissance against a Windows 11 VM. 
Detected the attack using Windows Filtering Platform Event ID 5156 and completed 
a full triage analysis of the inbound connection attempt.
